## 硬规则：图文结合（最重要）

**只堆文字的卡片等于没做。** 每页必须有一张真实界面图，图占版面 ≥ 40%，文字最多三条。

- 禁止连续两页纯文字；只有「边界/声明」页允许文字为主，但也要配一张产品图。
- 图片必须是**目标项目的真实截图**，不是示意图、不是库存图、不是 AI 生图。
- 封面用品牌页/登录页/主界面，收尾用产品主视觉，不用纯字封面。

### 素材来源顺序

1. 目标项目的在线 demo / 官网（首选）：真实流程截图。
2. 仓库 `docs/images`、README 里的产品截图与结果图。
3. 都没有时，才退到产品图 + 数据图拼版。

### 取材流程（先抓素材，再写文案）

1. 打开项目官网/仓库，把「产品 → 客户 → 平台 → 追问 → 出稿 → 回查 → 编辑」每一步截一遍，2381×1339、DPR 1 即可（材料图，最终会缩放裁切）。
2. 落在 `_work/imgs/`，命名 `flow-1.jpg…flow-N.jpg`；仓库图另存 `ui-*.png`、`art-*.png`。
3. 只有素材齐了才动笔写卡片，文案围绕**图上真实可见的东西**写，不写图上没有的功能。

### 抓不到图的常见坑

- ModelScope / 在线 demo 是 iframe 包裹：先 `page.frames()` 找到 URL 含项目域名的那个 frame 再操作，直接访问子路由会白屏。
- 登录页若演示账号公开（如页面写「测试账号 xxx / 密码 xxx」），可直接登录抓全流程；凭证只用于截图，不写进交付物。
- 截图出现「演示」水印时保留原样，不 P 掉（会失真），靠裁切避开水印密集区。

## 截图呈现（必做）

真实界面要**包进系统窗口**，不要裸贴：

- macOS 窗口：圆角 18、浅灰标题栏 56px、左侧红黄绿三点（`#FF5F57`/`#FEBC2E`/`#28C840`）、标题居中灰色 17px；浏览器页把标题换成白底地址条。
- Windows 窗口：标题栏左侧品牌色小方块 + 应用名，右侧 `– □ ✕`。
- 窗口内截图 `object-fit: cover`，裁上部；整册至少 4–5 页用窗口，其余可出血贴边，形成节奏。
- 封面**禁用登录页、空白表单、报错页**。封面要「产品正在工作」的画面（选品、成稿、平台页），优先给窗口边框 + 完整留边，而不是糊一层遮罩。

## 视觉系统（避免「土」）

配色必须从**目标产品自身**取，先看它的主界面截图，再定色板：

- 底色：近白 `#FFFFFF` + 一层极淡品牌色氛围光（radial 4–18% 透明度）。**禁用暖米色/象牙黄纸底**，那是模板味最重的来源。
- 主色：产品 UI 里的强调色（如玫红 `#D42B5C`），只用于标签、数字、方点，一页最多两处。
- 字色：`#15151A` 主 / `#3A3A44` 次 / `#86868F` 注释。

版式规则：

- **不要把字摆在四个角。** 只留右下页码 `03 / 12`，其余角一律空着；栏目标签放标题上方，不放到页眉右上。
- 边距：左右 150 px、上下 120 px；图片可以出血到边，文字永不出血。
- 字号阶梯只用四级：标题 168/96 / 小标 54 / 正文 32 / 注释 22。
- 大标题用衬线体（Noto Serif SC 900），正文用无衬线（Noto Sans SC 300/500）。
- 标题栏宽小于 900 px 时，标题降到 76 px，宁可两行也不出孤字断行。
- 表格不要框线，只用 1px 浅分隔线（`#EEECF1`）。
- 不放 emoji、图标、色块拼贴、多层渐变。

## 出血与遮罩

- 全出血截图 + 白渐变遮罩压字时，遮罩靠字一侧必须接近纯白（`#FFF` 到 38%，之后才衰减），否则底图里的原文字会透出来，显脏。
- 截图不描边、不用大投影，只给一层极轻 `0 32px 80px rgba(21,21,26,.10)`；分栏页让图出血到画布边缘。
