# 报告出图管线 
- **deck-builder** — 把 Word/PPT/PDF 报告稳定产出一套「同尺寸、同体积、同质感」的图片集 + PPTX。固定画布 54.98×30.92cm(16:9)，一次栅格化，python-pptx 组装，可机器校验。用于 Pivot Studio 个人项目报告（1037 拼拼这类）的批量交付。 （`reporting/deck-builder/`）
- **riffle-biz-deck-jpg** — 生成 16:9 编号 JPG 系列图（商业介绍/作品展示，10–20 张），画幅 4762×2678、`fig/<slug>/NN.jpg`。当用户要做商业介绍图、作品图集、riffle 同款图时调用。 （`reporting/riffle-biz-deck-jpg/`）
