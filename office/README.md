# 办公文档（Word / Excel / PPT / PDF） 
- **office** — Create, edit, inspect, or convert Office documents, spreadsheets, presentations, and PDFs. （`office/office/`）
- **office-docx** — Create, read, edit, and validate Word documents (.docx). （`office/office-docx/`）
- **office-export-pdf** — Convert an Office document to a requested PDF with LibreOffice Kit. （`office/office-export-pdf/`）
- **office-pptx** — Create, read, edit, and validate PowerPoint presentations (.pptx). （`office/office-pptx/`）
- **office-recalculate** — Refresh spreadsheet formula caches and verify calculated values with LibreOffice Kit. （`office/office-recalculate/`）
- **office-render** — Render requested document images or inspect visual layout with LibreOffice Kit. （`office/office-render/`）
- **office-xlsx** — Read, create, edit, and validate Excel workbooks, data, and formulas (.xlsx). （`office/office-xlsx/`）
